__init__() Function:
It acts like a constructor. It gets called every time an object is created. the use of self in it's parameter basically refers to the object.

self is basically a reference to the current instance. it is used to access the reference variable.
class Student:
  def __init__(self, fullname):
    self.name = fullname
    print("adding new Student in Database")
s1 = Student("Karan")
print(s1.name)   #Karan

Constructors are basically of two types - default and parameterized
Class attributes: Variables which have common values for all instances. it is accessed like - class.atr. It is stored only once in the memory.
for eg: Value of college name for all instances will be same.

Instance attributes: Variables which have different values for different instances. Sytax: obj.attr
eg: The value of student name for all instances.

If we have class and object attributes with the same name then the object attributes take precedence over class precedence.

class Account:
    def __init__(self, acc_no, balance):
        self.acc_no = acc_no
        self.balance = balance
    def debit(self, amount):
        self.balance+=amount
    def credit(self, amount):
        self.balance-=amount
    def get_balance(self):
        return self.balance
acc1 = Account(1000, 2000)
print(acc1.balance)
print(acc1.acc_no)

                     Private attributes & methods
These attributes are meant to be used only within the class and are not accesssible from outside the scope of the class. An attribute can be made private by simply adding two underscore before it, same goes for function as well. We may ask ourselves that why should we make our functions private hence making it impossible to be used by other objects, but making it private means those functions are generally used by other functions in the code.
