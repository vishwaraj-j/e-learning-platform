                           Lists
Built-in data types. It can store elements of different types(integer, float, string, etc).

program:
marks = [1,2,3,4]
print(type(marks)) 

o/p: <class 'list'>
We can apply indexing, and len() with lists.
We can store data of different types.
Lists are mutable in Python. Even though we kow that strings are immutable the following is absolutely possible in Python - 

programs:

marks = [1,2,3,"Priyanka"]
print(marks)
marks[3] = 'Sahoo'
print(marks)

o/p:

[1, 2, 3, 'Priyanka']
[1, 2, 3, 'Sahoo']

indexing and slicing are also applicable in lists. List1[0,2] means that elements having index 0,1 will be included. Negative indexing also applicable.

                            Tuples
A built-in data type. The difference between lists and tuple is that lists are mutable whereas tuple are not. Lists are written within square brackets whereas tuple are written within parenthesis.

programs:
marks = (1,2,3)
print(type(marks))

o/p: 
<class, 'Tuple'>

program:
marks = (1,2,3)
marks[0] = 6

o/p: This will give an error. As tuples are not mutable. It is not possible to assign a different value to an element.

If we write a single element in a tuple, like this marks = (1), the python interpreter will perceive it as a single element and will print it like this - o/p: 1. But if we write it like this - marks = (1,), the single element will be perceived as a tuple with single element. But the same is not true for Lists. we don't have to write it with commas if there is a single element. 

Tuple built-in methods:

tup.index(element)    #returns index of first occurence
tup.count(element)  #counts the total number of occurences of the element.
